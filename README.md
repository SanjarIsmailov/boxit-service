## ✦ About BOXIT

**BOXIT Services** is a modern London-based moving and property-services website designed around one simple idea:

> **Make moving simple.**

The website brings multiple services together under one reliable team — from moving and packing to furniture delivery, cleaning and practical handyman support.

The interface focuses on:

- Clean premium design
- Strong BOXIT branding
- Mobile-first responsiveness
- Simple navigation
- Clear pricing
- Fast quote requests
- WhatsApp communication
- Smooth animations
- Easy service discovery
